# TasksCLI 📝
A professional CLI Todo manager with unique ID generation and persistent storage.

## Installation

### Linux/macOS
1. `git clone https://github.com/yourusername/Tasks-CLI.git`
2. `cd Tasks-CLI`
3. `chmod +x install.sh && ./install.sh`

### Windows
1. Clone the repo.
2. Run `install.bat`.
3. Add the folder path to your **System Environment Variables (Path)**.

## Usage Examples
- **Add a task:** `tasks add "Buy coffee"`
- **list all tasks:** `TasksCLI list`
- **list all tasks that are done:** `TasksCLI list mark-done`
- **list all tasks in progress:** `TasksCLI list in-progress`
- **list all tasks to-do:** `TasksCLI list todo` 
- **Update:** `TasksCLI update <ID> "New Description"`
- **Delete:** `TasksCLI delete <ID>`
